\# AI Based Fruit Quality Detection



An AI-based web application that detects fruit type and freshness from an uploaded image using a Convolutional Neural Network (CNN).



\## Features



\- Fruit image upload

\- Fruit type detection

\- Fresh or Rotten classification

\- Prediction confidence

\- Image preview

\- Professional web interface



\## Supported Fruits



\- Apple

\- Banana

\- Orange



Each fruit is classified as Fresh or Rotten.
